# Admin panel

React, Vite, TypeScript, Tailwind CSS v4, and shadcn/ui foundation for the club management admin panel.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## UI components

The project uses the shadcn/ui CLI and Radix Nova preset. Add components with:

```sh
npx shadcn@latest add <component>
```

## Fonts

Google Fonts are loaded from `src/index.css`. The Tailwind font utilities include `font-poppins`, `font-mukta`, `font-montserrat`, `font-open-sans`, `font-work-sans`, `font-roboto-slab`, `font-space-mono`, and `font-roboto`. Poppins is the default UI font; Montserrat is configured for headings.
